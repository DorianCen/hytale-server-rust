# T04 — Connection packet codegen

**Status:** todo
**Agent fit:** medium (depends on T03/T05; bounded generated output)
**Depends on:** T03, T05
**Owns:** `tools/protocol-gen/**`, `crates/hytale-protocol/src/generated/**`,
`crates/hytale-protocol/src/lib.rs` (module declarations only)

## Goal

Generate Rust types and encode/decode for the connection packet family from the
IR, using the wire primitives from T05. Prove the generator→compiled-code path
end to end.

## Read

- `/tmp/connection.json` or the checked-in fixture from T03
- `crates/hytale-protocol/src/io.rs` (from T05)
- `Connection.java` and `Ping.java` for field semantics
- [`PORTING.md`](../PORTING.md) §4

## Work

1. Create `tools/protocol-gen` as a Rust binary:

   ```text
   protocol-gen connection --ir <connection.json> --out crates/hytale-protocol/src/generated
   protocol-gen --check
   ```

2. Emit:
   - `generated/connection.rs` with structs for `Connect`, `Ping`, `Pong`,
     `NetworkTick`, `ClientDisconnect`, `ServerDisconnect`,
     `InsecurePlayerOptions`, `RequestInsecurePlayerOptions`;
   - enums for the connection enums, with `from_value`/`value`;
   - `Packet` implementations (`id`, `channel`, `compute_size`, `encode`,
     `decode`) for packets whose IR is complete.
3. Keep the generated file header:

   ```rust
   // @generated by tools/protocol-gen. Do not edit.
   ```

4. Add a `generated/mod.rs` and wire it into `hytale-protocol`.
5. Tests in `crates/hytale-protocol/tests/connection.rs`:
   - round-trip representative values for `Connect`, `Ping`, `Pong`,
     `ServerDisconnect`, `ClientDisconnect`;
   - nullable fields both present and absent;
   - empty and maximum-length strings/arrays within bounds;
   - malformed input returns an error, not a panic.
6. `--check` regenerates to a temp dir and diffs; CI uses it.

## Out of scope

- No auth/setup/game packets.
- No byte-level Java fixture yet (T14/full codegen).
- No hand edits to generated files.

## Acceptance

```sh
cargo run -p protocol-gen -- connection --ir /tmp/connection.json --out crates/hytale-protocol/src/generated
cargo test -p hytale-protocol
cargo clippy -p hytale-protocol --all-targets -- -D warnings
cargo fmt -p hytale-protocol -- --check
```

Round-trip tests pass; `--check` is clean after regeneration.

## Handoff

Report the generated API, any IR fields that could not be generated, and the
regeneration command.
